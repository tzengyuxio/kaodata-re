# 信長の野望・天道 with パワーアップキット（NOBU13PK, Windows 日文版）頭像相關格式

`dekoei.py export nobu13pk-win` 用到的格式。來源是 Steam 版（appid 363110，見 `notes/steam.md`），匯出用到的 `grp/KAO_M.N13` 與 `scenario/sceda01–11、21–31.n13` 複製到 `games/nobu13pk-win/`。

## 頭像：grp/KAO_S.N13、KAO_M.N13、KAO_L.N13

- 同一組 1598 張臉有三種尺寸：S 60×60、M 96×120、L 240×240。依「不小於 64×80、最接近 64×80」的規則收 M。`EDIT_KAO_S/M/L.n13`（新武將用）的 1100 項都是空白。
- 檔案是 `LINK` 封裝：
  - +4 u32 項數。
  - +0x10 u32 矩形表的位置（0x3220）。
  - 0x20 起是每項的 (u32 位置, u32 大小)。
  - 矩形表每項 12 bytes：u16 x、y、寬、高，接 4 個 0。
- 每項是 `GT1G0600` 貼圖，+0x38 起是正方形貼圖（M 是 128×128）的 B、G、R、A 像素。只取左上的寬×高，大多是 96×120，另有 3 張不同，照原尺寸收（多出的列是實際的畫，不是補邊）。S（60×60）、L（240×240）全部同尺寸。

  | 項號 | 頭像碼 | 人物 | M 的尺寸 |
  | ---: | ------ | ---- | -------- |
  | 1222 | 0x04DB | 阿部良輝 | 96×126 |
  | 1242 | 0x04EF | 山崎吉家 | 96×122 |
  | 1396 | 0x17D4 | 伊東一刀斎 | 96×126 |

- 每張 5000–10000 色，alpha 全是 255，所以匯出成全彩（`rgbaBlobs`）。
- 匯出時每張存成無損 WebP（`faces/0000.webp`，kaodata 規格 §5 的 file 圖），不放 blob（2026-10-16）。

### 各尺寸的涵蓋範圍

✅ 比對：`research/face-crop/sizes.py`＋`sizes_nobu11_13.py`，織田信長（頭像 0），2026-10-21。BASE＝涵蓋範圍最大、其他尺寸由它裁出或縮出的那張（不一定像素最多）；框是 BASE 上的座標，rmse 是 0–255。[比較圖](../research/face-crop/sizes/nobu13pk-win.jpg)

| 尺寸（檔案／項） | 在 BASE 上的框 (x, y, w, h) | 倍率（BASE px／本身 px） | rmse | 涵蓋範圍 |
| ---------------- | --------------------------- | -----------------------: | ---: | -------- |
| 240×240（KAO_L.N13 第 0 項） | **BASE** | — | — | 整張 |
| 96×120（KAO_M.N13 第 0 項） | (73, 47, 96, 120) | 1.00 | 3 | 頭部，原尺寸直接裁 |
| 60×60（KAO_S.N13 第 0 項） | (61, 47, 120, 120) | 2.00 | 5 | 頭部的正方形，上緣和 96×120 相同，左右各寬約 12 px |

- `EDIT_KAO_L.n13` 的格子是 200×200（都是空白）。

## 頭像碼

人物記錄裡的是頭像碼，不是項號。換算在 `NOBU13PK.exe` 0x502ED0（`koei_games.nobu13_face_entry`）：

| 頭像碼 | 項號 | 用途 |
| ------ | ---- | ---- |
| 0–1197 | 0–1197 | 武將 |
| 1219–1337 | 1198–1316 | 武將（先減 21；1198–1218 和 1177–1197 是同一批臉，沒人用） |
| 4000–4023 | 1317–1340 | 姫 |
| 5001–5012 | 1341–1352 | 文化人 |
| 6000–6035 | 1353–1388 | 事件人物、一般角色、北条家等人的另一張臉 |
| 6050–6051 | 1389–1390 | 沒人用 |
| 6095–6105 | 1391–1401 | 名古屋山三郎、井伊直虎、斎藤福等 11 人 |
| 7000–7015 | 1402–1417 | 田村顕重、風魔小太郎（另一位）等 16 人 |
| 8000–8179 | 1418–1597 | 只有 8059（南蛮人）、8118（上杉竜若丸）有人用 |

- 換算表後面還有 1700–2799 一段，對到新武將用的 EDIT_KAO，不收。
- `portraits[].code` 填頭像碼（十六進位）。

## 劇本：scenario/sceda??.n13

- 檔頭是 `NOBU13SCENARIOVERSION00`、劇本說明與名稱，接一個 `LWC\x1a` 區塊（`ls11.lwc_decode`，同革新）。
- 解開後在 u32 0x14、u32 2600 之後是 2600 個人物槽，不定長（`koei_games.load_nobu13_win_persons`）：
  - +0 姓 11 bytes、+11 名 11、+22 姓的讀音 19、+41 名的讀音 19（Shift-JIS，讀音是平假名）。空槽全是 0。
  - 接著 153 bytes。
  - 再接四個「u32 個數＋個數 × u16」陣列。
  - 最後 137 bytes，其中 +68 是 u16 頭像碼。
- 22 個劇本（本體 01–11、PK 的 21–31）的槽都相同，只有名字隨年代改變。匯出用劇本 11（慶長大転封，関ヶ原之後）的名字，比照革新。
- 槽 1190、1191 是「長尾虎」（謙信女性說）與「世良田元信」（家康影武者說）。劇本 11 裡他們的名字已變成「上杉謙信」「徳川家康」，所以這兩人改用劇本 1 的名字。
- 頭像碼在劇本之間只有三處不同：
  - 織田信長在劇本 30 用 6026。
  - 長尾晴景在劇本 02 用 368。368 是岡部元信的臉，看來是資料錯誤，不收。
  - 槽 2240 的佐吉在劇本 26 換成上杉竜若丸（8118）。

## 槽的分配

- 武將（收成人物，共 1344 人）：0–1360（有空槽），以及 2290–2305。
- 頭像碼 0 是織田信長的臉。槽 2000–2069 的先代（益子勝宗……架空実父）頭像碼也是 0，代表沒有臉，比照革新不收。
- 以下的臉不另立人物，照用途分組：
  - 1600–1690 `姫`：用 4000–4023，多數幾人共用一張，不取名；只有一人用的臉取那人的名字（織田市、斎藤帰蝶、浅井茶々等）。槽 2241 女中、2267 女也借用其中兩張。
  - 2200–2211 `文化人`：今井宗久、千利休、フロイス等，各一張。
  - 2240–2283：
    - 一般角色（老人、農民、足軽、忍者等）分到 `一般人物`，以角色名命名，同一張臉給多種角色時用「／」並列。
    - 有名有姓的分到 `事件人物`（佐吉、土田御前、おね、竹千代、樋口与六等）。
    - 和武將同名的（北条氏康、氏政、氏直、幻庵、織田信長）是該武將的另一張臉（說話、生氣等表情），放進他的 `expressions`。
  - 玄広恵探、栴岳承芳用的是今川良真、今川義元的臉，不另收。
- 沒人用的 180 張（6050、6051 與 8000 段的其餘臉）分到 `其他頭像`，用途沒有追。
- PK 版和無印版的差異沒有比對（沒有無印版），所以沒有標 `pk`，網站上也就沒有 PK 的頭像或人物群組（2026-10-19 使用者確認先維持這樣）。
  - Steam 版只有 with PK，無印版沒有單賣；說明書 `Nobu13PKManual.pdf` 與 `ReadMe.txt` 都沒有列追加武將的名單或人數。
  - 可能的線索（未查證）：頭像碼 1219–1337（項號 1198–1316，119 張）是「先減 21」接上去的一段，前面 1198–1218 和 1177–1197 是同一批、沒人用的臉，看起來是後來追加的區塊，和革新的 PK 頭像排在本體頭像區之後相似。
  - 以後要標 `pk` 的做法：查這段臉的人物在槽號上是否也是接在後面的一段（比照革新）、找外部的 PK 追加武將名單對照，或取得無印版比對。
