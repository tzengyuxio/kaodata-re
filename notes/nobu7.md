# 信長之野望・將星錄（NOBU7, Win 中文版）頭像相關格式

`dekoei.py export nobu7-win` 用到的格式。來源是 `games/5.31_信長之野望七_killpeople.rar`（killpeople 是上傳者標記），解到 `games/nobu7-win/`（不含動畫），說明文字檔放在 `games/nobu7-win-src/`。

## Kaodata.nb7：頭像

- 開頭是 u32 張數（769），接著每張 16 bytes：u32 offset、u32 大小（5120）、u32 寬（64）、u32 高（80）。
- offset 從索引表結束處（4 ＋ 769 × 16＝12308）起算。
- 每張是未壓縮的 64×80、8 bit 色號，只用到色號 10–245。

## Grppal.nb7：色盤

- LS11，2 段，每段 768 bytes。頭像用第 0 段。
- 每色是 B、R、G 各一個 byte。色號 0–9 是填充值（ffff00），匯出時改成黑色。

## Sndata01–05.nb7：人物

- 5 個劇本各一檔。0x53D0 起有 744 筆、每筆 0x5C bytes 的人物記錄（`koei_games.load_nobu7_win_persons`）：
  - +0：姓（8 bytes Big5）
  - +8：名（8 bytes Big5）
  - +0x1C：u16 頭像（就是 Kaodata.nb7 的第幾張）
  - +0x50：u16 人物序號（1–744）
- 5 個劇本的人物和頭像都相同，只有姓名不同：
  - 序號 163：劇本 1、2 是松平元康，3–5 是德川家康
  - 序號 350：劇本 1、2 是長尾景虎，3–5 是上杉謙信
  - 劇本 3 的公主寫成外字（`C769`…），其他劇本都是「姬一」…「姬十六」
- 匯出用劇本 5 的姓名。
- 外字：`Gaiji.nb7` 是 8 個 16×16 點陣字形，長宗我部、香宗我部兩個姓用它們排出來：
  - `EB9F EBA0 EBA1`＝長宗我部（長宗我部國親、元親、信親、盛親）
  - `EBA2 EBA0 EBA1`＝香宗我部（香宗我部親泰）
  - 3 個字形壓著畫出 4 個字，所以只在 `koei_games.NOBU7_WIN_GAIJI` 整串對照。

## 匯出

- 頭像碼是 4 位 16 進位的頭像序號。
- 序號 1–716 匯出成角色，一人一張臉（織田信長是第 0 張）。
- 下列不算角色：
  - 717–732：「姬一」到「姬十六」，是還沒取名的公主。她們用的 716–731 和沒有人用的 732–739 都是公主臉，分到「公主」組。
  - 733–744：10 位農民（農民越藏等）和佚名１、２，共用第 740 張臉。這張命名為「農民」，分到「其他頭像」。
- 沒有人用的 741–768 是僧侶、公家、南蠻人、武士等臉，分到「其他頭像」。
- `Saveda01.nb7` 是存檔，不使用。
