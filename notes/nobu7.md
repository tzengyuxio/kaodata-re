# 信長之野望・將星錄（NOBU7, Win 中文版）頭像相關格式

`dekoei.py export nobu7-win` 用到的格式。來源是 `games/archives/win/5.31_信長之野望七_killpeople.rar`（killpeople 是上傳者標記），解到 `games/nobu7-win/`（不含動畫），說明文字檔放在 `games/archives/win/nobu7-win-src/`。

## Kaodata.nb7：頭像

- 開頭是 u32 張數（769），接著每張 16 bytes：u32 offset、u32 大小（5120）、u32 寬（64）、u32 高（80）。
- offset 從索引表結束處（4 ＋ 769 × 16＝12308）起算。
- 每張是未壓縮的 64×80、8 bit 色號，只用到色號 10–245。

## Grppal.nb7：色盤

- LS11，2 段，每段 768 bytes。頭像用第 0 段。
- 每色是 B、R、G 各一個 byte。色號 0–9 是填充值（ffff00），匯出時改成黑色；只匯出到頭像用到的色號 245（kaodata 的 255 是透明色）。

## Sndata01–05.nb7：人物

- 5 個劇本各一檔。0x53D0 起有 744 筆、每筆 0x5C bytes 的人物記錄（`koei_games.load_nobu7_win_persons`）：
  - +0：姓（8 bytes Big5）
  - +8：名（8 bytes Big5）
  - +0x1C：u16 頭像（就是 Kaodata.nb7 的第幾張）
  - +0x50：u16 人物序號（1–744）
- 5 個劇本的人物和頭像都相同，只有姓名不同：
  - 序號 163：劇本 1、2 是松平元康，3–5 是德川家康
  - 序號 350：劇本 1、2 是長尾景虎，3–5 是上杉謙信
  - 劇本 3 的公主寫成外字（`C769`…），其他劇本都是「姬一」…「姬十六」
- 匯出用劇本 5 的姓名。
- 外字：`Gaiji.nb7` 是 8 個 16×16 點陣字形，長宗我部、香宗我部兩個姓用它們排出來：
  - `EB9F EBA0 EBA1`＝長宗我部（長宗我部國親、元親、信親、盛親）
  - `EBA2 EBA0 EBA1`＝香宗我部（香宗我部親泰）
  - `EBA3 EBA4 EBA5`＝五右衛門（石川五右衛門）、`EBA6 EBA4 EBA5`＝又右衛門（荒木又右衛門），寫在名的欄位
  - 3 個字形壓著畫出 4 個字，所以只在 `koei_games.NOBU7_WIN_GAIJI` 整串對照。早期的匯出漏了後兩個，把它們當 Big5 解成亂碼。

### 能力

- 人物記錄 +0x16 政治、+0x18 戦闘、+0x1A 智謀（u16），+0x30 起是足軽、騎馬、鉄砲、水軍的適性（u16，1–6 對 E D C B A S）（`koei_games.load_nobu7_win_stats`，`dekoei.py nobu-person nobu7-win`）。
- 名稱：Steam 日文版 EXE 是 政治 戦闘 智謀、足軽 騎馬 鉄砲 水軍；中文版 EXE 是 政治 戰鬥 智謀、步兵 騎兵 步槍 水軍。
- +0x10 是生年（信長 1534），+0x12 像是元服年（未確認）。
- 劇本年在檔頭：01 1551、02 1560、03 1570、04 1582、05 1582；PK 06–10 是 1555、1562、1575、1584、1589。約 45 人的值隨劇本不同。
- 沒有截圖可以對照；中文版和日文版劇本 5 的能力欄完全相同，信長、家康的適性和烈風伝一致。

## 匯出

- 頭像碼是 4 位 16 進位的頭像序號。
- 序號 1–716 匯出成角色，一人一張臉（織田信長是第 0 張）。
- 下列不算角色：
  - 717–732：「姬一」到「姬十六」，是還沒取名的公主。她們用的 716–731 和沒有人用的 732–739 都是公主臉，分到「公主」組。
  - 733–744：10 位農民（農民越藏等）和佚名１、２，共用第 740 張臉。這張命名為「農民」，分到「其他頭像」。
- 沒有人用的 741–768 是僧侶、公家、南蠻人、武士等臉，分到「其他頭像」。
- `Saveda01.nb7` 是存檔，不使用。

## Steam 版 with パワーアップキット（`nobu7pk-win`）

`dekoei.py export nobu7pk-win` 用 `build_nobu7_win(pk=True)`。來源是 Steam 版（appid 628100，見 `notes/steam.md`），`KAODATA.NB7`、`grppal.nb7`、`SNDATA05.NB7` 放在 `games/nobu7pk-win/`。

- `KAODATA.NB7`、`grppal.nb7`、`Gaiji.nb7` 和中文版逐 byte 相同，所以頭像、色盤和 `nobu7-win` 相同。
- 劇本 `SNDATA01–10.NB7`：記錄排法同中文版，姓名是 Shift-JIS，外字碼相同。PK 多了 5 個劇本，但 10 個劇本都是同樣的 744 人、同樣的頭像，所以 PK 沒有新角色，不標 `pk`。劇本 5 的頭像對照也和中文版完全相同。
- 寫法因劇本而異的：163 松平元康／徳川家康、350 長尾景虎／上杉謙信、242–244 羽柴／豊臣（只有劇本 10 是豊臣）、717–732 的公主在劇本 3、8 寫成「もんた一」等，其他是「姫もん一」等。照中文版用劇本 5 的姓名。
- 記錄裡沒有讀音。group 用日文寫法「姫」，其他同中文版。

## 人物欄位（全部）

本節的位址：`Nobunaga7WPK.exe`（Steam PK 版）用 SteamStub 3.1 加殼，解殼方法同 `notes/san8.md`（AES-256-CBC 解 `.text`），VA 指解殼後的映像（image base 0x400000）。中文版 `Nobu7.exe` 沒有對照到位址，名稱表從它的 Big5 字串取。

- 劇本檔讀進記憶體的程式是 `Nobunaga7WPK.exe` VA 0x423b50（從 0x43b130 呼叫，存檔是 0x420fe0）：檔案的每一筆 0x5C bytes 展開成 0xC0 bytes 的記憶體物件（陣列在 0x542348，物件表 0x57e9b8，筆數 0x2E8＝744）。下表「記憶體」欄是物件內的位移，用來對照程式。
- 欄位名稱來自武将一覧的欄位表（VA 0x538b0c，每項是「標籤指標、寬度｜欄位號 << 16、欄」，顯示的 switch 在 0x425840，跳躍表 0x425f28；通用取值的跳躍表在 0x426658）。

### 中文版與 PK 的差異

- 劇本 5（1582）只差姓名和序號 590 土居（狀態、身分、勲功）。
- 劇本 1–4 每個劇本約 150 人的值不同，是 PK 改過的仕官年、登場年、狀態等。PK 另有劇本 6–10。
- 結論：中文版給繁中姓名，PK 給修正後的資料和多 5 個劇本。koei-wiki 的主資料集要用哪一個未定；若要繁中，可以用 `nobu7-win` 的姓名配 `nobu7pk-win` 的數值（序號相同）。

## 地理

### 城（劇本檔）

- 城表 64 筆、每筆 0x34 bytes，城號 1–64，城 k 在 0x469C＋0x34·k（第 1 筆從 0x46D0 開始）。讀入程式是 `Nobunaga7WPK.exe` VA 0x4ae970（從 0x43b030 呼叫，存檔 0x4aed60），記憶體物件 0x90 bytes，陣列 0x5dba28（物件表 0x57e99c）。
- 欄位（從記錄開頭算）：

| 位移 | 欄位 | 可信度 |
|---|---|---|
| +0x00 | 城號 | ✅ |
| +0x02 | 城名（10 bytes）；隨劇本改名（觀音寺→安土、稻葉山→岐阜）。1 號是內城（薩摩） | ✅ |
| +0x0C | 城主勢力（大名號 1–30） | ✅ data |
| +0x0E | 規模？（現值、上限各一） | 🟡 |
| +0x10–+0x1E | 8 個有上限的數值，推定是防禦、兵士、金、兵糧、軍馬、鉄砲、大砲等，順序沒有對過 | 🟡 |
| +0x22／+0x24 | x／y，在 Mapdata.nb7 的 176×151 格上；畫出來城都落在陸地 | 🟡 data |
| +0x26 | 0–11；安土是 11，VA 0x4f87dc 把 11 換成 0x41。推定是城的樣式，對應 Atkmap.nb7 的 12 張攻城圖 | 🟡 |
| +0x28 | ？ | ❌ |
| +0x2C | 城主（人物序號） | ✅ data |
| +0x2E | 指向 0x57ea0c 的陣列 | ❌ |
| +0x30 | 下一座城（鏈結串列） | 🟡 |

- 大名表：0xD0＋0x118·(號−1)，30 筆。+0 大名號、+2 大名本人的序號、+6 起 30 個 u16 的外交關係（0 自己、5 普通，其他值 1／3／7／9／11／15）、+0x10E 本城的城號。
- 劇本年在檔頭（u16 年、u16 ？、u16 劇本號）。

### 國、地方、相鄰

- EXE 裡沒有令制國名；城不屬於任何「國」。
- 中文版 EXE 有 12 個地方名（蝦夷 陸奧 出羽 關東 東海 甲信 北陸 近畿 山陰 山陽 四國 九州），但找不到城和地方的對照。❌
- 城與城之間沒有相鄰表：部隊在大地圖的六角格上自由移動（【推】，沒有讀移動程式）。要給 koei-places 的 `adjacent`，只能用座標推，或者不填。

### 地圖與戰場圖

- `Mapdata.nb7`：26576 bytes＝176×151 的地形格，排法是 index＝x·151＋y（`reshape(176,151).T`）。畫出來南北顛倒（未和畫面確認）。🟡
- `Mainmap.nb7`（27 MB）是大地圖的圖。`Hexmap.nb7` 是 32 片等角六角拼塊，`Msmap.nb7` 是 18 張 712×304 的圖。
- `Atkmap.nb7`：12 張 768×512、8 bit 的攻城圖。檔頭 u32 張數，接張數 × 16 bytes（位置、大小、寬、高），資料從 4＋16n 起。色號只用到 10–237。
  - 色盤是 `Grppal.nb7` 第 0 段（B、R、G，和頭像相同）。🟡 code＋看圖：畫面程式從 GRPPAL 讀第 `[obj+0x225a]` 段（VA 0x463fe0），這個值只會被設成 0 或 1（VA 0x4643b0 拒絕 ≥2），再設定色號 10–245（VA 0x46406c）；第 0 段畫出來是正常的城郭、護城河與樹林，第 1 段整片偏紅。
  - 之前判斷「色盤不對」，是因為圖上有整格的橘紅、藍色方塊。那是畫在圖裡的格子記號：藍格是各曲輪的據點，橘紅格是相鄰的格子，右下角一大片是攻方的布陣區。第 1 段把這些格子畫成灰色石板，所以這些色號本來就是格子專用。
  - 選圖 ✅ cross：城用第（城記錄 +0x26）張。`Atkdata.nb7` 是 65 筆 × 642 bytes（VA 0x4065d0 讀第 n 筆：seek (n−1)×0x282），第 k 筆是城 k 的攻城資料，+0x26＝11（安土樣式）的城改讀第 65 筆（VA 0x4f87dc）。每筆開頭是格子座標（u16 筆數＋筆數 ×（x, y）像素，40×40 一格，0xFFFF 分隔），用到的 11 種樣式（0–8、10、11）各取一座城，第一組座標都正好落在第（+0x26）張圖的藍格上，後面幾組落在相鄰的橘紅格上。樣式 9 沒有城用，第 9 張不匯出。
  - 同樣式的城，`Atkdata` 前段相同、後段略有差異（樣式 0 的 7 座城有 6 種內容），沒有逐欄解。
  - 樣式會隨劇本改：觀音寺在 PK 劇本 4、5、9 是 11（安土），其他劇本是 7。
- `Atkgrp.nb7`（127 張，40×40 等大小，u32 張數＋16 bytes 索引，色號 0–237）推定是攻城戰的部隊與記號圖塊，沒解。
- 野戰推定在大地圖上打，沒有獨立的野戰圖（【推】）。

## koei-wiki 匯出

`dekoei/wiki_nobu7.py`。三個指令都在 `dekoei/` 下執行：

```sh
../.venv/bin/python dekoei.py places-export nobu7pk-win --game-dir ../games/nobu7pk-win --out ../export/koei-wiki/places
../.venv/bin/python dekoei.py persons-export nobu7pk-win --game-dir ../games/nobu7pk-win --out ../export/koei-wiki/persons --places ../export/koei-wiki/places
../.venv/bin/python dekoei.py biography nobu7pk-win --game-dir ../games/nobu7pk-win --out ../export/koei-wiki/nobu7pk-win.jsonl
```

- 主資料集 `nobu7pk-win`：數值取 Steam PK 的 10 個劇本（`SNDATA01–10.NB7`，從 `games/steam/628100/` 硬連結到 `games/nobu7pk-win/`），`name` 取中文視窗版（`../nobu7-win`），日文寫法不同時放 `nameJa`。人物與城的序號兩版相同。
- **人物**（koei-persons/1）：716 人，也就是 kaodata 的角色（序號 n 是 id n−1）。717 以後的姫一–十六、農民、佚名不匯出。
  - 人物層級的值取 PK 劇本 5（1582），和 kaodata 取名的劇本相同。
  - `scenarios` 列 PK 的 10 個劇本，待機、死亡的劇本不列。年份取檔頭的 u16。`status` 是狀態名；大名的 `lord` 填自己；`loyalty` 只給大名、浪人以外的人。
  - 標籤照 PK 的 EXE 字串（`Nobunaga7WPK.exe` VA 0x521584–0x521680）：狀態「大名 現役 独立 浪人 待機 一向 農民 死亡」，狀態 4 寫「姫」；身分「足軽頭 侍大将 部将 家老 宿老 大名」。
  - `relations`：父、配偶照記錄，0 是無。子女、兄弟由父欄反推（遊戲判斷兄弟也是用父欄），表外的祖先（2000 以上）也算同父。
  - `uncertain` 標了 debut（+0x12）、寿命、義理、口調，還有戦闘特技裡的騎突（bit 0）。
  - 讀音和歿年取自日文列伝的標頭（記錄裡沒有），有列伝的 700 多人才有。
- **地點**（koei-places/1）：64 城，`level`「城」，id 是城號 1–64。
  - 名稱取劇本 5，其他劇本的寫法列在 `notes`。
  - `pos` 是 +0x22、+0x24（176×151 格，標 uncertain）。
  - 沒有國、地方、相鄰。
  - `battlemaps`：每城一筆或兩筆攻城圖（`role`「攻城」），檔名 `Atkmap_NN.png`，NN 是城記錄 +0x26，取 10 個 PK 劇本出現過的樣式；`sharedWith` 列出用同一張圖的城。共 11 張 768×512 PNG。
  - 檢查：635 項、0 筆不符。
- **列伝**：中文版 `Message.nb7`（LS11，30 段）和 PK `message.nb7`（45 段）的第 2–15、29 段。
