# 信長の野望・新生 with パワーアップキット（NOBU16PK, Steam）頭像格式

只做了分析，還沒有匯出（2026-10-16）。來源是 Steam 1336980（`games/steam/1336980/`，版本 1.1.7），日、英、繁中、簡中的執行檔都在同一個目錄。

## 尺寸

`NOBU16_FaceTool_ReadMe_JP.txt` 寫的是每位武將 5 張：

| 名稱 | 尺寸 | 用途 |
| ---- | ---- | ---- |
| 特大 | 717×1020 | 事件 |
| 大 | 512×512 | 情報畫面、演出 |
| 中 | 306×180 | 選擇武將 |
| 小 | 176×272 | 訊息 |
| 極小 | 72×72 | 部隊列表 |

比照三國志13 PK、大志 PK，收 72×72。

## 封裝

- `RES/res_face.bin` 和大志的 `res_face.bin` 同格式（見 `notes/nobu15.md`）。外層 `LINK` 有 7 項，每項是 7000 格的 `LINK`，資料是 LWC 壓縮。
- PK 的臉在 `RES_PK/res_pk.bin`。外層有 428 項，其中第 386–392 項是 7000 格的頭像 `LINK`。

| 外層項 | 內容 | 張數 |

- 512×512 第 0 組、176×272 多了一張 4234。
- PK（`res_pk.bin` 第 386–392 項）有 50 張：新增 11 張（2311–2321），換掉 39 張本體的臉。第 93 項另有 41、2239 兩張 512×512。
- 沒有 DLC 頭像資料夾。人物、名字還沒追。
