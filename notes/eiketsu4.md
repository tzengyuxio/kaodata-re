# 織田信長傳（EIKETSU4, Win 中文版）頭像相關格式

`dekoei.py export eiketsu4-win` 用到的格式。來源是 `games/archives/win/6.7_英傑傳四織田信長傳_killpeople.rar`（killpeople 是上傳者標記），包內的 `Ekd4/` 解到 `games/eiketsu4-win/`（不含 `TESTAVI.AVI`），說明文字檔和 `wing/`（WinG 安裝程式）放在 `games/archives/win/eiketsu4-win-src/`。

- 英傑傳系列第 4 作（光榮的檔名代碼是 EKD4，資料檔副檔名 `.E4`），主程式 `Ekd4.EXE`。
- `UNKOEI.exe`／`unKOEI.dat`／`rmKOEI.bin` 是上傳者附的工具，匯出不讀 EXE。

## KAO.E4：頭像

- LS11（`ls11.ls11_decode_parts`），219 段，每段 5120 bytes＝64×80、8 bit 色號，沒有其他壓縮（同 `KAO.E2`）。
- 只用到色號 10–143。頭像碼就是段的索引。

## 色盤：PMPALET.E4

- LS11，123 段（地圖、劇情畫面用），每段最多 256 色 × 3 bytes，順序是 **B、R、G**。色號 0–9 是填充值（fff700）。
- 156 段的色號 10–143 完全相同（`SPALET.E4` 也是），其餘 17 段是夜晚之類的變色。匯出用 PMPALET.E4 第 0 段的 10–143，0–9 改成黑色。

## 人物：DATA.E4 第 0 段

- 645 筆，每筆 77 bytes（`koei_games.load_eiketsu4_win_persons`）：
  - +0：姓名，12 bytes Big5
  - +13：頭像碼的 ASCII 十進位寫法（3 字元）
  - +28：u16 頭像碼
- 記錄的分段：
  - 0–184：武將（其中 25–29、59–69 是「沒有」空位）
  - 185–199、640–644：「沒有」
  - 200–521：兵種（刀兵1…、槍騎兵1…、忍者、軍師、山賊、海盜、僧兵、野武士、暴動兵、民眾）
  - 522–602：無名 NPC（武將13、家臣1、居民1、老人1、公卿1、宣教師1、妾1、姬1、商人1、鐵匠…）
  - 603–639：劇情人物（織田信長2–7、寧寧、近衛前久、歸蝶、阿市、千利休…），以及居民3／4、農民3／4、刑人、床上病人上／下
- DATA.E4 其他段是武器、地名、兵種名、技能等，和頭像無關。

## 匯出

- 武將與劇情人物，依記錄順序每個名字一人，共 186 人。
  - 同一人的別名合併（`EIKETSU4_WIN_ALIASES`）：織田信長2–7→織田信長、松平元康→德川家康、長尾景虎→上杉謙信、阿濃／打大鼓的濃姬→歸蝶、千宗易→千利休、木下藤吉郎→羽柴秀吉。
  - 有兩張臉的加 `label`，第一筆記錄的臉當 `face`：織田信長 0 青年、1 壯年（織田信長2–4、6 用 1）；羽柴秀吉 5「羽柴秀吉」、4「木下藤吉郎」。
  - 日吉丸、喜平次、孫四郎、寧寧、近衛前久、正親町天皇、斯波義統、鳥居強右衛門用的是 NPC 的臉（男孩子、妾、公卿、使者），照樣算人物。
  - 不同人共用一張臉的照實保留，例如佐久間盛政／長續連（148）、吉川經家／田山義慶（147）、北條氏直／松田憲秀（140）、筱原長房／奧田忠高（174）、織田信孝／明智光安（97）、洛利延斯／弗羅義斯（46）。
- 只有兵種、NPC 用的臉，以第一筆記錄的稱呼（去掉編號）命名，兵種歸「部隊」，其他歸「一般人物」。
- 219 張都有記錄用到，沒有未使用的臉。
- `nameHistorical`：神原康政→榊原康政、北田具教→北畠具教、田山義慶→畠山義慶（榊、畠不在 Big5 裡）。佐佐成政、高阪昌信、筱原長房是同字異形或通用寫法，不填。
