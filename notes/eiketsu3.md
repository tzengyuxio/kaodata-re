# 毛利元就傳（EIKETSU3, Win 中文版）頭像相關格式

`dekoei.py export eiketsu3-win` 用到的格式。來源是 `games/win/[系列] 英傑傳/毛利元就傳 (中文).zip`，解到 `games/eiketsu3-win/`（不含 WAV、AVI、MP3）。zip 裡的檔名是 Big5，用 Python `zipfile` 解（cp437 → Big5）。

- 英傑傳系列第 3 作（光榮的檔名代碼 EKD3，資料檔副檔名 `.E3`），日文原名《毛利元就 誓いの三矢》。
- dataset id 比照 `eiketsu4-win`／`eiketsu5-win` 取 `eiketsu3-win`。
- 主程式 `毛利元就傳_Gr.EXE`（Win32 PE，沒有加殼，imagebase 0x400000，.data VA 0x47C000＝檔案 0x7B000），下文的位址都是 VA。

## KAO.E3：頭像

- LS11，332 段，每段 12544 bytes＝**112×112**、8 bit 色號，沒有其他壓縮。
- 色號 0 是背景（遊戲裡蓋掉，顯示成洋紅色的填充），匯出時改成透明（255）；其他只用到 10–174。
- 0x4103E8 畫頭像，段號對 332（0x14C）取餘數，經 0x41023A 從 `KAO.E3` 讀出。頭像碼就是段的索引。

## 色盤：PMPALET.E3

- LS11，順序是 **B、R、G**，色號 0–9 是填充值（fff700）。
- 164 段的色號 10–174 都相同，匯出用第 0 段，0–9 改成黑色。

## 人物：DATA.E3 第 0 段

- 800 筆，每筆 54 bytes（`koei_games.load_eiketsu3_win_persons`）：
  - +0：姓名，13 bytes Big5
  - +13：讀音（半形片假名）
  - +28：u16 頭像碼
  - +30：u16，另一個編號（戰場角色？），匯出不用
- 0x402922 把記錄讀進人物物件（0x497F78 起，每個 0x50 bytes），頭像碼放在物件 +4；兩個畫頭像的地方都經 0x42DE80 直接取 +4，沒有依人物換臉。
- 記錄的分段：
  - 0–199：武將與劇情人物（181 夫人、183 少輔太郎、184 少輔次郎、185 德壽丸、186–199 家族與劇情人物）
  - 200–247：隨機姓名的家臣（加藤權六等），共用 287–293、297 八張臉
  - 248–499：NPC（工匠、家臣、武將、士兵、百姓、農民、老人、男孩、女孩、行者、雲遊僧、僧侶、說書人、近侍、王公、傳教士、藥師、兵法家、夫人、公主、負責官、商人、練武官）
  - 500–791：兵種（槍隊、弓隊、騎兵隊、弓騎兵隊、步槍隊、砲隊、習武者、忍者、女忍者、軍師、強盜、海盜、僧兵、運輸隊、鼓笛隊、毛利軍士兵、侍女）
  - 792–799：劇情人物（毛利弘元、元就之母、毛利幸松丸、竹若丸、竹千代、神秘僧侶、松平元康、妙姬）

## 不同年齡的臉

- 有 51 張臉沒有記錄用到。其中多數緊接在某人的臉之後，畫的是同一人不同年齡：
  - 0–3 毛利元就（少年、青年、壯年、老年；記錄用 1）
  - 4–6 毛利隆元、7–9 吉川元春、10–12 小早川隆景（少年的臉也是少輔太郎、少輔次郎、德壽丸用的）
  - 13–14 毛利輝元、15–16 陶晴賢、17–19 山中鹿之介、20–22 織田信長、23–25 德川家康（23 是竹千代）、26–27 安國寺惠瓊（26 是竹若丸）、29–30 妙姬
  - 42–73 的偶數是 16 位毛利家臣（福原貞俊到香川光景），下一張奇數是同一人年長的樣子
- EXE 裡找不到換臉的程式（物件 +4 只在讀記錄時寫入），應該是劇本（`R_*.EEX`、`S_*.EEX`，編譯過的 bytecode）裡改的，沒有追。年齡的 label 是看圖判斷的。

## 匯出

- 記錄 0–199 和 792–799，每個名字一人，共 201 人。
  - 同一人的別名合併（`EIKETSU3_WIN_ALIASES`）：少輔太郎→毛利隆元、少輔次郎→吉川元春、德壽丸→小早川隆景、竹千代／松平元康→德川家康、竹若丸→安國寺惠瓊、夫人→妙姬（同一張臉）。
  - 上一節的年齡臉放進 `face`／`expressions`，加 `label`（`EIKETSU3_WIN_LOOKS`、`EIKETSU3_WIN_PAIRS`）；`face` 是記錄用的那張。
  - 不同人共用一張臉的照實保留：隆元之妻／元就之母（116）、長介／高橋鑑種（91）。
- 只有 NPC、兵種用的臉，以第一筆記錄的稱呼（去掉編號）命名：士兵和記錄 500 起的兵種歸「部隊」，其他歸「一般人物」；隨機姓名家臣的臉叫「一般武將」。
- 剩下 21 張沒人用的臉（28、151、159、211、308–322、324、327）歸「未使用」。308 以後多是和 323–331 同一批畫風的武將臉。
- 角色用到的臉放 `portraits.bin`，其他放 `extra.bin`。
- `nameHistorical`：神原康政→榊原康政、佐佐成正→佐佐成政、下間賴簾→下間賴廉。
