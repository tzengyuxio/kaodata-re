# 成吉思汗 蒼狼與白鹿IV 威力加強版（GENGHIS4PK, Win 中文版）頭像相關格式

`dekoei.py export genghis4pk-win` 用到的格式。

- 來源是 `games/win/成吉思汗 IV-威力加強版/`（已安裝的目錄），複製到 `games/genghis4pk-win/`，不含 AVI、WAV、`MP3/`。
- 主程式 `CKW95.EXE`（Win32 PE，imagebase 0x400000，.data VA 0x5D5000＝檔案 0x1D3800），下文的位址都是 VA。
- 無印版在 `games/6.3_成吉思汗四_killpeople.rar`（`yuan4/`，`Men.bmp`／`Women.bmp`），還沒做；要做的話 game code 用 GENGHIS4（PK 版另用 GENGHIS4PK，同 SAN4PK）。

## MENPUK.BMP／WOMENPUK.bmp：頭像

- 8 bit 的 Windows BMP，每格 64×80：
  - MENPUK.BMP：1280×2720，20 欄 × 34 列＝680 格
  - WOMENPUK.bmp：896×1040，14 欄 × 13 列＝182 格
- 無印版的 MEN.BMP（620 格）、WOMEN.BMP（168 格）是 PK 版的前段：女性 168 格相同，男性 615 格相同。
- 0x46BA30 取男性頭像：碼是 u16，超過 0x2A7（679）就用 679；沒有人物時用 0x269（617，空白格）。
- 0x46BAB0 取女性頭像：碼是 u8，超過 0xB5（181）就用 181。
- 空白的花紋格：男性 616、617、664–679，女性 159、175–181。

## 色盤

- 兩張 BMP 的色盤相同。
- 色號 0–9、246–255 在 BMP 裡都填洋紅色（ff00ff），那是 Windows 的保留系統色。
- 頭像只用到其中的 0（黑）、5（暗洋紅，寶石、耳環）、255（白，反光），照系統色的預設值換掉。
- kaodata 的 255 是透明色，所以色號 255 的點改成沒用到的 254，254 設成白色。

## 人物：SCEDAT1–4.CK

- 4 個劇本各一檔。前段是劇本說明、國家、都市、技術等，之後依序是男性、女性人物記錄（`koei_games.load_genghis4_win_persons`）。
- 男性每筆 51 bytes：
  - u16 序號，接著 17 bytes 姓名（Big5，NUL 之後補空白）
  - 從姓名起算：+40 固定是 `11 11`（用來找區段），+44 是 u16 頭像
- 女性每筆 24 bytes（0x495F10 依序讀進物件 +0、+2、+0x13、+0x14、+0x18、+0x19、+1）：
  - u8 序號、17 bytes 姓名、國家、u16、u8、u8（固定 2）、u8 頭像
  - 頭像在最後一個 byte（物件 +1，0x46BAB0 讀的就是它）
- 男性區段的開頭用「連續 10 筆 +40 都是 `11 11`」來找；女性區段緊接在後。
- 各劇本人數：男 204／149／145／126，女 31／27／25／29。

## 匯出

- 劇本 1–4 依序，先男後女，同性別、同名、同頭像的只留第一次，共 629 人（男 519、女 110）。
- 同名但頭像不同的視為不同人，各自保留：帖木爾滅里、高宗、巴札特、瑪格麗特、安潔拉。
- 頭像碼照 `koukai3-win` 的寫法：「性別 << 12 | 頭像」。
- 沒有人用的格子分組：
  - 空白花紋格歸「空白」（26 張）
  - 其他歸「其他頭像（男）」（259 張）、「其他頭像（女）」（64 張）
  - 遊戲裡沒有固定記錄的武將（新武將、子女等）會用到這些臉
- 外國人名不填 `nameHistorical`（比照 `liberty-dos`）。
