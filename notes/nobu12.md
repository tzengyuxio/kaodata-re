# 信長の野望・革新 with パワーアップキット（NOBU12PK, Windows 日文版）頭像相關格式

`dekoei.py export nobu12pk-win` 用到的格式。來源是 Steam 版（appid 363090，見 `notes/steam.md`），匯出用到的 `Grp/KAO_M.N12` 與 `scenario/sceda12.n12` 複製到 `games/nobu12pk-win/`。

## 頭像：Grp/KAO_S.N12、KAO_M.N12、KAO_L.N12

- 同一組 1379 張臉有三種尺寸：S 56×70、M 96×120、L 240×240。依「不小於 64×80、最接近 64×80」的規則收 M。`EDIT_KAO_S/M/L.N12`（新武將用）的 1000 項都是空的。
- 檔案是 `F11N` 封裝：+4 u32 項數（兩次），0x14 起每項 20 bytes（u32 1、矩形位置、資料位置、id、id）。
- 每項資料是 `T11N`、u32 寬、高、貼圖寬、高、2 bytes，接貼圖大小的 B、G、R、A 像素（M 的貼圖是 128×128）。只取左上的寬×高。
- alpha 全是 255，每張臉最多 255 色，所以轉成逐張色盤（`portraitPalettes`，色號照第一次出現的順序），色號 255 留給透明、不會用到。
- M 只有 1 張不是 96×120：項 1348（頭像碼 0x0544，`諸勢力` 的江尻商人衆）是 100×125，照原尺寸收。S（56×70）、L（240×240）全部同尺寸。

## 劇本：scenario/sceda??.n12

- 檔頭是 `NOBU12SCENARIOVERSION02`、劇本名稱與說明，接一個 `LWC\x1a` 區塊：u32 原始大小、u32 壓縮後大小（小端序）、+12 起 256 bytes 字典、+0x10C 起是 LS11 碼（`ls11.lwc_decode`）。
- 解開後約 2 MB。0x9BA6 起是 1940 筆 213 bytes 的姓名記錄：+0 姓（11）、+11 名（11）、+22 姓的讀音（19）、+41 名的讀音（19），Shift-JIS，讀音是平假名。
- 人物記錄跟在 u32 0x13、u32 1940 之後，共 1940 筆、不定長：四個「u32 個數＋個數 × u16」陣列（前兩個固定 3 個），接 u16 槽號（空槽是 0xFFFF），再接 174 或 176 bytes 的本體。本體最後 68 bytes 的開頭是 u32 頭像號，後面是生年、元服年、歿年與能力值。長度不固定，所以從下一筆的開頭往回找頭像號（`koei_games.load_nobu12_win_persons`）。
- 8 個劇本（01–05、PK 的 10–12）的 1526 人和頭像都相同，只有名字隨年代改變（木下秀吉→羽柴秀吉→豊臣秀吉）。匯出用最後的劇本 12（關ヶ原之後），名字是一般最熟悉的寫法。

### 能力

- 記錄本體最後 40 bytes 起（頭像號之後 +28）是 u32 統率、武勇、知略、政治（`koei_games.load_nobu12_win_stats`，`dekoei.py nobu-person nobu12pk-win`）；頭像號之後 +56 的 u32 是俸禄。
- ✅ capture（web）：`status-screens/nobu12-win-web-01.jpg` 佐竹義斯 統率 63、武勇 53、知略 46、政治 65、俸禄 400，和解出值相同。
- 8 個劇本的值都相同；劇本 01 是 1555 年。

## 頭像的分配

- 槽 0–1099 是武將，各用一張不同的臉：0–999 與 1229–1328。
- 槽 1000–1099 的 100 人（最上義忠 … 加藤段蔵，含真田十勇士）用的是 1229–1328，排在本體頭像區（到 1228）之後，判斷是 PK 追加，標 `pk`。
- 其餘的槽不是武將，頭像不另立人物，照用途分組，只有一人用的臉取那個人的名字：
  - 1000–1022 `姫`：槽 1300–1382 的公主共用 1000–1019（每張 4–6 人，不取名），1020–1022 是織田市、斎藤帰蝶、明智玉子專用。
  - 1023–1034 `文化人`：今井宗久、千利休、近衛前久、フロイス等。
  - 1035–1053 `事件人物`：佐吉、岐秀、土田御前、おね等，以及農民、足軽、僧兵、家老等一般角色（國人眾、水軍眾等的部將也借用這些臉）。
  - 1329–1378 `諸勢力`：各地國人眾、水軍眾、寺院住職、忍者眾、商人眾的首領與南蠻商人。
  - 1054–1228 沒有人用，分到 `其他頭像`；有一般武將、女性、能面、虛無僧，以及幾張信長的不同版本，用途沒有追。
- 槽 1433–1467（三好元長等先代）的頭像號是 0，但 0 是織田信長的臉，這些人沒有頭像。

### 勢力（段 20）

段頭 `(0x14, 0x3C)`：60 槽，52 個有名字。每筆找 `08 00 00 00 <c u16> ff×14 01 00 00 00 <c u16>` 這個鍵，之後是：u32 n＋成員 u16、8 個 0 byte、u32 k＋妻 u16、u32 m＋m×6 bytes、4 bytes、u32 k＋拠点 u16、8 bytes、u32 当主槽號。sceda01 驗了 51/52（当主的 +14 勢力和自己一致）；27 足利家（将軍）的版面不同，没解出当主。

## 列伝

`Msg/Bfile01.n12`–`Bfile22.n12`（N12F 訊息檔），22 檔 × 50 人＝1100 筆，順序＝槽號 0–1099。

N12F：+4 u32 字串表位移、+8 u32 項數 n，0x14 起 n 個 u32 是 token 索引；token 在 0x14+4n 到字串表之間，以 `,\n` 分隔（`&,MSGnnn` 引用字串、`(,Fnc000`、`\x0F`）。字串表：u32 個數 cnt、u32 首號，cnt+1 個 u32 位移，字串接在位移之後（cp932）。第 2j 項是名字、2j+1 項是本文，本文裡字面的 `\n` 是換行。

名字和槽號對不上的 31 筆都是別名（✅ cross）。槽 1100 以後沒有列伝。`Kfile*.n12` 是家宝說明（Kfile01 從九十九髪茄子開始），留給道具那一輪。

中文版：Steam 只有日文 PK 版，本地沒有繁中版【推：沒另外查】。

- **国**（60 筆）：段 10，place id 是国號＋1000，`level`「国」。国的相鄰與地方沒找到。
- **城／港／館**（133 筆）：id 是段 8 的拠点槽號（0–179，空槽跳過）。
  - 段 11 的記錄長度不固定：22 bytes 尾段之後接 0、1 或 2 個 62 bytes 的區塊（舊筆記只寫了 0 或 1 個），用「下一筆的名字與平假名讀音」判斷界線。
