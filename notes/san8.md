# 三國志VIII with パワーアップキット（SAN8PK, Windows 日文版）頭像相關格式

`dekoei.py export san8pk-win` 用到的格式。來源是 Steam 版（appid 628040，見 `notes/steam.md`），匯出用到的檔案複製到 `games/san8pk-win/`。

## 版本與 EXE

- `San8WPK.exe` 也有 SteamStub 3.1 DRM（同三國志VII，見 `notes/san7.md`）：`.text` 檔案 0x1000 起 0x2D0000 bytes 是 AES-256-CBC 加密的。解開標頭後 +0x50 是程式區大小，+0x58 金鑰、+0x78 IV（先用金鑰做 ECB 解密）、+0x88 被搬走的前 16 bytes（接在密文前面一起解）。匯出不讀 EXE。

## KOEI 封裝檔：g_maindy.s8、p_main.s8

- 檔頭 `KOEI`，+8 u32 資料起點，+16 u32 位移表的 bytes 數，位移表（u32）從 +0x18 起。第 n 項在「資料起點＋12＋位移[n]」（`sango.koei_archive`）。
- g_maindy.s8 有 2339 項：0–845 是 160×180 的大頭像，846–1691 是同樣 846 張的 64×80 小頭像，之後是其他畫面圖。kaodata 只收 64×80。
- 頭像號就是第幾張（0–845）。
- p_main.s8 第 4 項是頭像的色盤：256 × (R, G, B, flags)。
- 小頭像沒有用到色號 0（綠色 `#00ff00` 去背色），色號 255 有用到，所以匯出時把 255 換成 0，色盤第 0 色改成原本的第 255 色。

## 頭像的分配

- 人物用到 0–653（531、533 除外）。
- 581 和 655–701 之中的 31 張和 563–593 的事件人物頭像逐 byte 相同，不匯出。
- 沒人用的頭像依畫面分組：
  - 654–704：`事件人物`（虎、老仙人、女性、孩童等）
  - 531、533、705–775、806–829：`其他頭像（男）`
  - 776–805、830–845：`其他頭像（女）`
- EXE 裡沒找到選臉清單，所以沒有依遊戲內的分類、也沒標 `pk`。
- 人物用到的頭像依頭像號切成約 1 MB 一包（`portraits.bin`–`portraits3.bin`），沒人用的放 `extra.bin`。

## 人物：D_Sce.s8

- 明文，沒有編碼。
- 人物表從 0x2437 起，658 筆 × 0x4F bytes，依讀音排序：
  - +0 u16 編號（0–657）
  - +2 姓 5 bytes，+7 姓的讀音 11 bytes
  - +0x12 名 5，+0x17 名的讀音 11
  - +0x22 字 5
  - +0x27 u16 頭像號
- 文字是 Shift-JIS，讀音是半形片假名，空白補齊。外字用 `S8gaiji.tte`，和三國志VII 的代碼相同，另外多了 U+E013 顗、U+E025 璝、U+E03D 瓘、U+E063 淩（`sango.SAN8_GAIJI`）。
- 頭像號和三國志VII 的武將編號一致：関羽 2、張飛 1、劉備 36、曹操 60。
- 匯出時 `id` 就是記錄編號，`reading` 是姓、名讀音轉平假名，中間空一格。
- 不當成人物的記錄：
  - 職稱：老母、皇后、密使、文官、武官、勅使、町民、書生、倭人、闇商人、異民族、老人、県令。只有職稱用到的頭像，改成有 `name` 的 `事件人物` 頭像。
  - 単福：徐庶的化名，用的是同一張臉。
- 共用頭像的人物：関定與劉泌（588）。另外，張温、李豊、馬忠各有兩個不同的人。
