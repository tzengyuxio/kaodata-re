# 三國志VIII with パワーアップキット（SAN8PK, Windows 日文版）頭像相關格式

`dekoei.py export san8pk-win` 用到的格式。來源是 Steam 版（appid 628040，見 `notes/steam.md`），匯出用到的檔案複製到 `games/san8pk-win/`。

## 版本與 EXE

- `San8WPK.exe` 也有 SteamStub 3.1 DRM（同三國志VII，見 `notes/san7.md`）：`.text` 檔案 0x1000 起 0x2D0000 bytes 是 AES-256-CBC 加密的。解開標頭後 +0x50 是程式區大小，+0x58 金鑰、+0x78 IV（先用金鑰做 ECB 解密）、+0x88 被搬走的前 16 bytes（接在密文前面一起解）。匯出不讀 EXE。

## KOEI 封裝檔：g_maindy.s8、p_main.s8

- 檔頭 `KOEI`，+8 u32 資料起點，+16 u32 位移表的 bytes 數，位移表（u32）從 +0x18 起。第 n 項在「資料起點＋12＋位移[n]」（`sango.koei_archive`）。
- g_maindy.s8 有 2339 項：0–845 是 160×180 的大頭像，846–1691 是同樣 846 張的 64×80 小頭像，之後是其他畫面圖。kaodata 只收 64×80。
- 頭像號就是第幾張（0–845）。
- p_main.s8 第 4 項是頭像的色盤：256 × (R, G, B, flags)。
- 小頭像沒有用到色號 0（綠色 `#00ff00` 去背色），色號 255 有用到，所以匯出時把 255 換成 0，色盤第 0 色改成原本的第 255 色。

### 各尺寸的涵蓋範圍

✅ 比對：`research/face-crop/sizes.py`＋`sizes_san8_10.py`，関羽（頭像 2），2026-10-21。BASE＝涵蓋範圍最大、其他尺寸由它裁出或縮出的那張（不一定像素最多）；框是 BASE 上的座標，rmse 是 0–255。[比較圖](../research/face-crop/sizes/san8pk-win.jpg)

| 尺寸（檔案／項） | 在 BASE 上的框 (x, y, w, h) | 倍率（BASE px／本身 px） | rmse | 涵蓋範圍 |
| ---------------- | --------------------------- | -----------------------: | ---: | -------- |
| 160×180（g_maindy.s8 第 2 項） | **BASE** | — | — | 整張 |
| 64×80（第 848 項） | (31, 41, 96, 120) | 1.50 | 23 | 只有頭部，160×180 上 96×120 的一塊 |

- rmse 比三國志IX（9）、X（7）的 64×80 高，應是同一張畫縮小後重新減色【推】。

## 頭像的分配

- 人物用到 0–653（531、533 除外）。
- 581 和 655–701 之中的 31 張和 563–593 的事件人物頭像逐 byte 相同，不匯出。
- 沒人用的頭像依畫面分組：
  - 654–704：`事件人物`（虎、老仙人、女性、孩童等）
  - 531、533、705–775、806–829：`其他頭像（男）`
  - 776–805、830–845：`其他頭像（女）`
- EXE 裡沒找到選臉清單，所以沒有依遊戲內的分類、也沒標 `pk`。
- 人物用到的頭像依頭像號切成約 1 MB 一包（`portraits.bin`–`portraits3.bin`），沒人用的放 `extra.bin`。

## 人物：D_Sce.s8

- 明文，沒有編碼。
- 人物表從 0x2437 起，658 筆 × 0x4F bytes，依讀音排序：
  - +0 u16 編號（0–657）
  - +2 姓 5 bytes，+7 姓的讀音 11 bytes
  - +0x12 名 5，+0x17 名的讀音 11
  - +0x22 字 5
  - +0x27 u16 頭像號
- 文字是 Shift-JIS，讀音是半形片假名，空白補齊。外字用 `S8gaiji.tte`，和三國志VII 的代碼相同，另外多了 U+E013 顗、U+E025 璝、U+E03D 瓘、U+E063 淩（`sango.SAN8_GAIJI`）。
- 頭像號和三國志VII 的武將編號一致：関羽 2、張飛 1、劉備 36、曹操 60。
- 匯出時 `id` 就是記錄編號，`reading` 是姓、名讀音轉平假名，中間空一格。
- `nameHistorical`：田与→田予（「与」是錯字，日文把田豫寫成田予；`SAN8PK_WIN_NAME_HISTORICAL`，2026-11-02 和使用者的三國志能力表（Google 試算表，2015）對照後補）。
- 不當成人物的記錄：
  - 職稱：老母、皇后、密使、文官、武官、勅使、町民、書生、倭人、闇商人、異民族、老人、県令。只有職稱用到的頭像，改成有 `name` 的 `事件人物` 頭像。
  - 単福：徐庶的化名，用的是同一張臉。
- 共用頭像的人物：関定與劉泌（588）。另外，張温、李豊、馬忠各有兩個不同的人。

### 能力

- 人物記錄 +0x2D 起依序是武力、知力、政治、魅力，各 u8（`sango.load_san8_stats`，`dekoei.py san8 person`）。+0x29、+0x2B 像是生年、歿年（u16）。
- 這是基礎值。✅ capture（web）：`status-screens/san8-win-web-01.jpg`（4Gamer，本體）曹操顯示 武力 68(+0)／知力 96(+5)／政治 94(+0)／魅力 96(+0)，解出 68／91／94／96，括號裡是加成。
- 658 筆全部在 1–100。

## 事件、插圖、道具（2026-11-08）

### 圖：KOEI 封裝裡的生像素

- `g_event.s8`、`g_maindy.s8` 等封裝（`sango.koei_archive`）的項目是 8 bit 生像素，沒有寬高也沒有色盤。寬度用相鄰列的相似度找（`guess_width`；寬 2w 時兩列一樣像，所以結果是偶數時再試 w/2）。
- 色盤在 `p_main.s8`（396 組，每組 256 ×（R, G, B, flag））。每張圖挑「相鄰點顏色差／隨機兩點顏色差」最小的一組（`pick_palette`）。第 168 組幾乎全黑，什麼圖都會選到它，排除。這個測試對馬和 400×396 的風景會選錯，所以各段限制候選範圍（`STILL_PALETTES`）。色號 0（#00FF00）是去背色，PNG 裡設成透明。
- 用途與色盤都是看縮圖判斷的 🟡；圖本身的像素 ✅ code。

### 文字：m_msg.s8

- 323 項。每項：u32 n，接著 n/4 − 1 個 u32 位移，位移從第 n byte 算起。文字是 Shift-JIS，夾著腳本碼（`$`＋u16…、行首 `@R`），每行以 NUL 結尾。腳本碼沒解，輸出只取 Shift-JIS 的連續片段（半形字元、數字以外的 ASCII 會漏）。
- `text/m_msg.csv`：全部 323 項，一個片段一列（項、第幾則、位移、文字），79304 列。
- `text/biographies.csv`：第 51–54 項是列傳 654 則，編號＝頭像號（楊奉 0、張飛 1、関羽 2、劉備 36、曹操 60）✅ cross，附用這張臉的人物 id 與姓名。`notes/san-biographies.md` 的三國志VIII 原本寫「沒找過」。
- koei-wiki 匯出讀 Steam 繁中版（depot 628042）（2026-11-10，`dekoei.py biography <dataset> --game-dir ../games/steam/<appid>-tchinese/depot --out ../export/koei-wiki/<dataset>.jsonl`，總表在 `notes/san-biographies.md`）：`m_msg.s8`、`D_Sce.s8` 和日文版同樣排法，cp950、沒有外字；每則是以 NUL 結尾的行，第二行起以 `@R` 開頭，結尾 `$"`。一則給用這張臉的第一人，kaodata 去掉的事件角色與單福用 id 列在 `san8_extras.ZH_ROLE_IDS`（繁中名不同，不能照名字排除）。622 人 ✅ cross；kaodata 643 人裡 21 人遊戲裡就沒有列傳（頭像 588 是関定與劉泌共用，也是空的）。
- `events/`：只有一則的項目是事件腳本，共 230 個（`index.csv` 列第一句，`scripts.txt` 是全文）。71–121 是各年的「情勢」（184–234 年）✅ code，其他是事件（朝廷的使者、同盟、計略…），哪個事件、觸發條件 ❌。

## 負面結論

- 用平滑度在全部 396 組色盤裡自動挑：第 168 組（幾乎全黑）每張都贏，馬與四季風景會挑到錯的；要排除 168、依段限制範圍才可用。
- `g_event.s8` 自帶的 72 組色盤套到事件圖上顏色都不對；不是這些圖的色盤，用途要等找到呼叫它的程式才值得再查。
- `RDText.s8`、`svd_sys.sav` 是空的或存檔設定，沒有文字。
