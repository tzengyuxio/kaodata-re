# 大航海時代 系列 人物屬性總覽

大航海時代、II、外伝、III、IV（PK HD）的航海者有哪些屬性，各解到哪裡。細節在 `notes/koukai.md`、`koukai2.md`、`koukaigd.md`、`koukai3.md`、`koukai4.md` 的「能力」段，這份只做總覽（2026-10-22 調查）。

- 符號（`~/.claude/re-common.md` §6）：✅ 已驗證　🟡 部分完成／推論　❌ 未解　【推】只靠對系列的認識
- 證據：`code` 指 EXE 字串或畫視窗的程式；`cross` 指別版同值。五款都沒有截圖。
- offset 都是相對一筆人物記錄的起點
- 讀取：`dekoei.py koei-person <dataset> --game-dir …`（`dekoei/koei_stats.py`），輸出 CSV

## 跨代觀察

- I 的 5 項到 II 擴成 7 項（加入航海術、剣技、魅力），外伝沿用 II 的記錄（拿掉姓名，offset 都減 24）。
- III 改成 6 項屬性加技能等級與語言；IV 再改成 6 個基本值，畫面上的 10 個能力由它們算出。
- 等級和經驗只有 I、II、外伝有；III 以後用技能等級。

## 解碼程式的已知問題

- 沒有。原本的 loader 只讀頭像和姓名，能力的讀取是新加的（`koei_stats.py`）。
- 大航海時代 IV 的 6 個值的順序已追到程式（2026-11-10，見 `notes/koukai4.md`「能力」）。

## 大航海時代（koukai）

`SHINARIO.CIM` 0x13AE（PC-98；DOS 0x13CE、PC-88 0x1320）起 21 × 10 bytes 的能力表，加上男性記錄。

| 類別 | 項目 | 狀態 | 位置／說明 | 證據 |
|---|---|---|---|---|
| 能力 | 統率力 判断力 知力 勇気 強靭さ | ✅ | 能力表 +1–5 | code: PC-98 0x311CE |
| 次要 | 年齢 | ✅ | 能力表 +0 | code |
| 等級 | 戦闘Lv 航海Lv | ✅ | 男性記錄 +0xF、+0x10 | code |
| 經驗 | 戦闘 航海 経験 | ✅ | 能力表 +6、+8 u16 | code |
| 所屬 | 国籍 | ✅ | 男性記錄 +0x13 高 4 bit | code |
| 次要 | 忠誠度 | 🟡 | 執行時才填（DS:0x125A） | code |
| 不明 | 男性記錄 +0x13 低 4 bit | ❌ | 41 人都是 1 | — |

## 大航海時代III（koukai3-win）

|---|---|---|---|---|
| 屬性 | 體力 智力 武力 魅力 運氣 信仰 | ✅ | +0x40–0x54 | code |

| 語言 | 14 種（0–3） | ✅ | +0x94–0xC8 | code |
| 次要 | 名聲、惡名 | ✅ | +0x24、+0x28 | code |
| 次要 | 生日 | 🟡 | +0x2C、+0x38、+0x3C | code |
| 次要 | 國籍、星座、血型、職業 | 🟡 | 執行時物件 +0x14、+0x18、+0x1C、+0x20（見 `notes/koukai3.md`「人物」） | cross |
| 次要 | 疲勞 | 🟡 | +0x58（只追到玩家） | code |

## 大航海時代IV PK HD（koukai4pk-win）

`JP/World0.dll`、`World1.dll`、`TC/World0.dll` 裡 235 × 56 bytes 的人物表。

| 類別 | 項目 | 狀態 | 位置／說明 | 證據 |
|---|---|---|---|---|
| 基本值 | 体力 敏捷 魅力 知力 精神 運勢 | ✅ | +0x20–0x25，複製到人物物件 +0xF+i，取名用同一個 i 查標籤表（`DK4HD_jp.exe` VA 0x1402ad2e0、0x1401c8930、0x1401c8980） | code |
| 能力 | 生命力 統率力 操船術 …（10 項） | ❌ | 不在記錄裡，推定由基本值算出 | code: 字串 |

| 次要 | 星座、所屬勢力 | 🟡 | +0x29、+0x2A（見 `notes/koukai4.md`） | cross |
| 不明 | +0x18、+0x1C u32，+0x28、+0x2C，+0x30 u32 | ❌ | — | — |

koei-wiki 人物匯出（性別、国籍、星座、所属，PK 模式的差異）見 `notes/koukai4.md`「koei-wiki 匯出」。
