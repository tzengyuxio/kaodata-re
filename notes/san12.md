# 三國志12 with パワーアップキット（SAN12PK, Steam 日文版）頭像與人物格式

已匯出成 `san12pk-win`（2026-10-16）。來源是 Steam 628080（`games/steam/628080/`）。

## 頭像：Data/KAO_*.S12

- `KAODATA.S12`：`S12.` 檔頭，+4 u32 資料大小 254，+8 u32 2000，0xC 起 250 bytes 是 2000 個頭像號的有無位元表（高位元在前），699 個＝本體 695 張加 800–803。
- `KAO_W_L`／`KAO_W_S`／`KAO_F_M`／`KAO_F_S.S12` 是同一組 2000 項、四種尺寸，`LINK` 封裝（同天道的 `KAO_M.N13`）：
  - +4 u32 項數 2000。
  - +0x10 u32 矩形表位置（0x3EA0），每項 12 bytes：u16 x、y、寬、高。
  - 0x20 起每項 (u32 位置, u32 大小)。
- 每項是 `GT1G0500` 貼圖：+0x26 的高低 nibble 是 log2 高、寬，+0x2C 起是 B、G、R、A。空號是 1×1。

| 檔案 | 臉的尺寸 | 貼圖 |
| ---- | -------- | ---- |
| KAO_W_L | 360×512 | 512×512 |
| KAO_W_S | 90×128 | 128×128 |
| KAO_F_M | 48×60 | 64×64 |
| KAO_F_S | 小臉 | 32×32 |

- 依「不小於 64×80、最接近」的規則是 `KAO_W_S` 的 90×128，但使用者決定改收 `KAO_F_M` 的 48×60（2026-10-16）。933 張都有 48×60 版；每張最多 2819 色、alpha 全是 255，所以仍匯出成全彩。
- 本體有 695 張。追加臉另有一份 `.dat`（u32 個數＋頭像號），圖檔排法相同：
  - `AddKao00/ADD00.dat`：800–803。
  - `PK/AddKao20/ADD20.dat`：180 張，補 PK 才有臉的人，如 99、129、185。
  - `PK/AddKao21/ADD21.dat`：1128–1146。
  - `PK/AddKao21/SP0.dat`：1150–1184。

### 48×60 在 360×512 上的裁切位置（2026-10-19 研究，未匯出）

kaodata 想要比 48×60 大的頭像，所以用 `KAO_F_M` 反推它在 `KAO_W_L` 上的框（腳本與 933 張的框在 `research/face-crop/`）：把大圖縮小後和小圖做模板比對（以大圖的 alpha 加權，FFT 掃倍率，再用 Nelder-Mead 細調 x、y、倍率，雙三次取樣）。

- `KAO_W_L` 的 alpha 把背景去掉了（邊緣有淡出），但 alpha 0 底下的 RGB 還留著完整的背景畫面；`KAO_W_S`、`KAO_F_M`、`KAO_F_S` 有畫好的背景。`W_S` 的人物比 `F_M` 小很多，`F_M` 不是由它縮出來的。
- 933 張全部對上：RMSE（0–255）中位數 10.7、95% 在 17 以內，框都在 360×512 之內。殘差主要來自小圖自己的背景。
- **每張一個框**：框是 4:5（48×60 的倍數），寬 70.8–198.8 px（中位數 114.8），位置也各不相同，沒有固定的裁切方式。所以照這些框從 `W_L` 裁，就能精確重現遊戲的 48×60 構圖。
  - 比對時要允許框超出人物、延伸到透明背景（覆蓋率門檻 0.6）；門檻 0.85 會讓約四分之一的臉找錯位置。
  - 寬度不到 96 px 的框有 89 張，做 96×120 時這些要放大；64×80 都不必放大。
- 小圖另外修過的：23 號的 48×60 把畫過臉的長槍拿掉了，912 號拿掉了手和筆。RMSE 20 以上的 34 張多半是 1110–1139 一類的漫畫風臉，框的位置是對的，差在小圖有黃色等底色。
- 遊戲沒有裁切表：LINK 的矩形表只是貼圖裡的位置。說明書的「新武将登録」、「武将編集」也只能從既有的臉挑，沒有匯入圖片的功能。
- 裁的時候不要 alpha、只取 RGB，背景就和 48×60 一樣是畫好的（`research/face-crop/samples.py`）。
- 逐張無損 WebP 的估計（30 張平均，Lanczos 縮小，不透明，參數同匯出：lossless、quality 100、method 6、exact）：64×80 約 8.0 KB／張、933 張約 7.3 MB；96×120 約 16 KB／張、約 14.6 MB。現在的 48×60 實際是 4.5 MB（平均 4.9 KB；`du` 因為磁碟區塊會顯示 7.3 MB）。都是檔案位元組的合計，不含約 130 KB 的 `dataset.json`。

## 劇本：Scenario/、PK/Scenario/Scenario*.dat

- `ILNK` 封裝：+4 u32 段數，+8 起是各段的位置。
- 第 0 段是明文，其餘各段用同一個種子 0xE0A 加密，整段一次解：
  - 解密函式是 `San12WPK.exe` 0x5F8D90（`.text` 被 SteamStub 3.1 加密）。AES 金鑰、IV 和被搬走的 16 bytes 在 bind 標頭（EP − 0xF0，依 SteamXor 解開）+84 起，IV 先用 AES-ECB 解，`.text` 再用 AES-256-CBC 解。
  - 亂數是 `s = s * 0x6C078965 + 0x3039`，取 `s >> 16`。
  - 剩 2 bytes 以上時先取一個亂數：奇數就再取一個，和下 2 bytes 做 word XOR；偶數（或只剩 1 byte）就再取一個 r，該 byte XOR `(r >> 8) ^ r` 的低 8 位。
- 人物段：PK 劇本是 438000 bytes（1500 筆 × 292 bytes），本體 396000 bytes。
  - 記錄是位元欄位，+0 的 11 bit 是人物號。
  - +4 名（5 bytes）、+9 姓（5 bytes）、+0xE 讀音（半形片假名，姓名連寫），Shift-JIS。外字在 U+E000 起，例如「公孫」。
  - 未用的位元常留有雜值。
- 頭像號是記錄 bit 482 起的 11 bit（+0x3C 的 bit 2 起），本體劇本（264 bytes 一筆）也在同一位置。頭像號和人物號無關，例如關羽 67→2、呂布 437→3、貂蝉 824→566。
- Scenario0（總表）830 人有名字，用到 793 張臉；夏侯惇在劇本 1、2、3、9、12、20 改用 1100（雙眼完好的臉），合計用到 794 張，933 張中 139 張沒用到：1101–1139、1142–1146、1150–1184（無雙聯動）、1266–1279、1600–1609、1900–1935（PK 新加的汎用臉，應是給新武將用）。
  - 0–548、800–831（女性）、900–964（信長的野望）、1150–1191、1225–1231（古代人物）、1298–1306 每人一張臉。
  - 汎用臉：1350–1409 的 60 個職稱人物（文官、兵士、山賊將等）共用 1000–1022 的 23 張（13 張被多人共用，共 50 人）；1410–1475 的「〇〇の父」等 66 人各用 1200–1265 一張。
- 外字（U+E000 起，即 SJIS F040 起）照讀音與史書推定：E000 瓚、E003 郃、E004 蒯、E006 傕、E009 詡、E00C 龐、E00D 繇、E00E 邈、E00F 騭、E011 闞、E012 玠、E014 邢、E015 歆、E016 闓、E018 譙、E019 琬、E01A 郝、E01D 褚、E025 璝、E032 綝、E037 笮、E038 祜、E039 蕤、E03B 毌、E03D 瓘、E03F 琰、E043 鞏、E044 眭、E04F 宓、E051 禕、E056 蹋、E05A 氐、E062 臏、E063 淩、E064 嬴、E065 璜、E06F 罃、E0D4 嬀（嬀覽，緊接戴員）。字型 `font/F_FONTJ.s12`（u32 字數 7832＋SJIS 碼表，F040–FC4B 共 509 個外字）的點陣還沒解，沒有用圖對過。
- Steam 檔裡沒有中文名（Big5、UTF-16、UTF-8 都搜不到「劉備」），只有日文。
- `PK/Msg/S12MSG03.s12` 是列伝（1089 則，順序同人物號）。這個檔沒有壓縮：u16 個數，接著是 (u16 高位, u16 低位) 的位置表。

## 匯出（`san12pk-win`）

- 遊戲目錄 `games/san12pk-win/` 是用到的 KAO_F_M、AddKao 與劇本檔（硬連結到 `games/steam/628080/`）。
- 933 張 48×60 全彩頭像，寫成逐張無損 WebP（`display.scale` 4）。`code` 是頭像號（十六進位）。
- 人物取 PK 的 Scenario0：830 個有名字的槽裡，用 1000–1022 的 60 個職稱槽（文官、兵士、山賊将…）不當人物，頭像歸「一般人物」、名字併成頭像名；其餘 770 人。夏侯惇在其他劇本用的 1100 放 `expressions`。
- 「〇〇の父」等 66 人沒有讀音，不寫 `reading`。
- 沒人用的臉：1101–1146「其他頭像」、1150–1184「真・三國無双」、1266–1279／1600–1609／1900–1935「新武將」。
- `pk`：本體（`Data/KAO_F_M.S12`、`AddKao00`）沒有的頭像 234 張；名字不在本體 Scenario0 的人物 134 人。
