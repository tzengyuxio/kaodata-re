# 三國志VI 威力加強版（SAN6PK, Windows 中文版）頭像相關格式

`dekoei.py export san6pk-win` 用到的格式。來源是 `games/archives/win/5.31_三國志六加強版_killpeople.rar`（killpeople 是上傳者標記）。

## 版本與解包

- rar 裡是安裝片：`San6cx.ace`＋`San6cx.C00`–`C38` 的 ACE 分卷，加上 InstallShield 安裝程式。`FILE_ID.DIZ` 寫「Cracked by Martin Wu」，拿掉了光碟檢查、影片與音軌。
- ACE 用 `acefile`（純 Python，放在 scratchpad 的獨立 venv）解開，裡面直接是遊戲檔，不用跑安裝程式。解出放在 `games/san6pk-win/`。
- `SAN6.EXE` 是 PE32（image base 0x400000；`.data` 在檔案 0x337800、VA 0x739000）。匯出不讀 EXE，只拿它當參考。

## KAODATA.S6：頭像

- u32 張數（685），接著 685 × (offset, size, w, h) 各 u32，再接圖。offset 從表尾（4 + 16 × 685）算起。
- 每張 96×120、8 bit 色號，沒有壓縮（11520 bytes）。頭像碼就是索引。
- 匯出時人物用到的 532 張依頭像碼平均分到 `portraits.bin`、`portraits2.bin`–`portraits4.bin`（各約 1 MB），沒人用的 134 張有 group 頭像放最後的 `extra.bin`。
- 第 0 張是洋紅色的空白占位圖（新武將空位的頭像碼是 0），不匯出。
- 521–538 和異族頭像逐 byte 相同：521–529 對應 541、542、545、546、547、548、543、544、549，530–538 都是 550。沒有人物使用，不匯出。

## 色盤：PALETTE.S6

- 3 個相同的 Windows LOGPALETTE：版本 0x300、256 色，每色 R、G、B、flags。
- 色號 246–255 和 0 是洋紅（`#ff00ff`）。頭像只用 0–245，而且只有第 0 張用到 0，所以匯出前 246 色（規格的 255 色上限內）。

## 人物：SNDATA01–23.S6

- 23 個劇本，每檔 650 筆人物記錄，從 0x17D04 起，每筆 650 bytes。
- 記錄 +0 姓 6 bytes、+6 名 6 bytes（Big5，NUL 後補空白），+12 起是字，+30 是 u16 頭像碼（`sango.load_san6_persons`）。
- 0–549 是人物，550–649 是 100 個新武將空位（「武將００」…，頭像碼 0）。
- 同一個人物編號在各劇本的姓名、頭像碼都相同。以人物編號的順序匯出，`id` 依這個順序重排。
- 520–549 是異族：南蠻、匈奴、烏丸、山越、羌、氐各有王 1 人與「武將」4 筆。4 筆武將的名字和頭像都相同，只收 1 人，所以共 532 人。
- 頭像碼 1–520、539–550 各有一人使用（馬忠 377、378 是兩個人，頭像不同）。
- `nameHistorical`：孔冑→孔伷、士變→士燮，以及 2026-11-02 和使用者的三國志能力表（Google 試算表，2015）對照後補的毋丘儉→毌丘儉、太史亨→太史享、傅儉→傅僉。苻健是《三國志・張既傳》的武都氐王，不填。

### 能力

- 人物記錄 +48 起依序是統率、武力、智力、政治、魅力，各 u16（`sango.load_san6_stats`，`dekoei.py san6 person`）。名稱照 `SAN6.EXE` 的 Big5 字串（繁中版寫「智力」）。
- 23 個劇本裡同一人的值都相同；0–549 全部在 1–100。
- 沒有遊戲畫面可以對照；和 `MISC_TABLE/` 參考表的 S06 欄一致（cross：関羽 96／98／80／72／96 等）。

## 列傳：MESSAGE.S6

- LS11，65 段；每段是 u16 筆數加上同樣筆數的 u16 位置（從段首算）。第 1–6 段共 521 則是列傳，第 k 則是頭像碼 k＋1 的人物，最後一則是「沒有列傳。」（`biography.san6_bios`，`dekoei.py biography san6pk-win`）。
- 只有一段，Big5，沒有外字。每行是 `\x01"`＋文字＋`\n`，結尾 `\x05\x05\x05`；換行是畫面折行，會斷在詞中間，匯出時接起來。
- 人物 0–519 都有列傳，和 kaodata `san6pk-win` 的 id 與姓名全部相同（✅ cross：`dataset.json`）。外族的 12 人（頭像 539–550）沒有。
- 第 0 段是自稱（俺、朕…），第 7 段起是事件與台詞，沒細看。

## 事件人物（651–674）

- `SAN6.EXE` 0x5F49D4 起有一串小函式，各自 `push 頭像碼; push 名; push 姓; push 0x28A–0x28F; call`，0x686681 等處的隱士事件用同樣的呼叫方式：
  - 651 華佗、652 司馬徽、653 許劭、654 于吉、655 左慈、656 管輅、657 紫虛上人、658 南華老仙
  - 659 陳留王／獻帝、660 貂蟬、664 靈帝、665 少帝
  - 661、666 百姓，662、670 士兵，671、672 武將，663 小孩／童子，667 老人（也用於曹嵩、關定），668 徐庶之母，669 文官／使者，673 侍女，674 蔡夫人
- 一張頭像有多個稱呼時取一個（659 獻帝、663 童子、667 老人、669 使者），group「事件人物」。

## 沒有人物使用的頭像

- 551–620、675–683 是男性，621–650、684 是女性。程式碼裡沒找到使用這些頭像碼的地方（新武將挑臉的範圍沒找到），只依畫面分成「其他頭像（男）」「其他頭像（女）」。

## koei-wiki 匯出

```sh
cd dekoei
../.venv/bin/python dekoei.py persons-export san6pk-win --game-dir ../games/san6pk-win --out ../export/koei-wiki/persons --places ../export/koei-wiki/places
```

讀取在 `dekoei/wiki_san6.py`（koei-persons/1）。

- **人物**：532 人，`id`、`name`、`stats` 同 kaodata 與 `stats/san6pk-win.jsonl`（逐筆比過）。只有繁中版，沒有 `nameJa`；錯字照遊戲寫法，史書寫法寫在 `notes`。異族每族 4 筆「武將」只列一人，劇本資料取第一筆。
- **劇本檔的檔頭**：u16 年、u16 月（SNDATA01 是 184 年 2 月）。
- **勢力**：0x7EF68 起 27 筆 × 0xC0 bytes，+10 是君主的人物 slot（0xFFFF 是空的；21–26 是六個異族王）。每個劇本的君主都剛好是 +44 等於該勢力號的人，✅ cross。
- **劇本名稱**：`SAN6.EXE` 0x34D338 起依序是主劇本 1–7、歷史劇本 1–7、「０ 單挑」、8–10、PK 的 8–12，和 SNDATA01–23 的年份一一對得上（如 08 義勇軍初陣 184、12 赤壁之戰 208、23 諸葛誕的崛起 257），對法是推定。`scenario` 用檔號 1–23。15 是「單挑」模式的資料（5 個君主，其他 520 人全部現役），不是開局配置，不匯出。
- **人物記錄的欄位**：
  - +12 字 → `courtesy`；+38 出生年 → `born`。注音（+18 起）全是空白，沒有讀音。
  - +32 身份、+34 狀況：`SAN6.EXE` 有兩張指標表，0x337EA0 是「群雄 太守 一般」，0x337EB0 是「現役 在野 未發現 待命 俘虜 死亡 搜索」，各由一個「取第 n 個字串」的小函式（檔案 0x5B92、0x5BE5）讀。欄位對到哪張表是照欄位名的順序推的，數值都說得通：每個劇本身份 0 的人數等於勢力數，而且都是勢力的君主；狀況 3 的人出場年（+36）一定大於劇本年，其他狀況一定不大於。
  - `status`：現役的人寫身份（群雄、太守、一般），其他寫狀況（在野、未發現、待命、俘虜、死亡）。待命就是後登場，照規格附 `debut`（+36 出場年）。
  - +44 勢力號 → `lord` 是該勢力的君主；+76 是所在都市，就是地點匯出的 `id`（0–50）。劉備 184 在薊、曹操 189 在陳留，和史實相符。待命、死亡的不填 `location`。
  - `loyalty`：+68，現役而不是群雄的人才填，標 `uncertain`。
  - +82：父親的人物 slot（袁譚→袁紹、關興→關羽、司馬昭→司馬懿等 99 人，和史書相符）；1000 以上是沒有父親記錄的兄弟群組號。`relations.father`、`children`、`siblings` 由它算出。+80 是血緣群組號（曹氏 241、孫氏 260），放 `relations.clan`，標 `uncertain`。
  - `hidden`：+84 相性；+118 的 bit 0–3 義理、4–7 野心、8–10 冷靜、11–13 勇猛（標 `uncertain`）。
- **沒填**：技能（+126 的 bit 順序有矛盾，見 `san-attributes.md`）、壽命、理想、成長、健康、氣力、士兵、+78（不是配偶）。事件人物 651–674 只有頭像，沒有人物記錄，不列。
- **檢查**：persons-export 9409 筆、koei-wiki `verify_persons.py san6pk-win` 25358 筆，0 筆不符。
