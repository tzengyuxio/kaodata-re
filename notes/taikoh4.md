# 太閤立志傳IV（TAIKOH4, Windows 中文版）頭像與人物格式

來源是 `games/archives/win/taiko4.rar`：裡面是 CloneCD 映像（`TAIKOU4.img`，2352 bytes 一個 Mode 1 磁區）。去掉磁區頭轉成 ISO 後，檔案解在 `games/archives/win/taikoh4-src/iso/`。匯出用的檔案複製到 `games/taikoh4-win/`：`FACE0.TG4`、`FACE1.TG4`、`SNR/SNR3.TR_`、`GAME/TAIKOU4.EXE`。

- 有 `00000404`（繁中）語系檔，訊息是 Big5，所以是繁中版。
- 光碟根目錄的 `TAIKOU4.EXE` 是 SafeDisc 外殼（有 `stxt` 區段）。`GAME/TAIKOU4.EXE` 是沒加殼的本體，檔案位置＝VA − 0x400000。
- 檔名以 `_` 結尾的檔案（`*.TR_`、`*.TG_`）是 SZDD（MS `COMPRESS.EXE`，`koei_games.szdd_expand`），安裝時才展開。

## 圖檔：*.TG4（`koei_games.tk4g_images`）

- `TK4G` 檔頭：
  - +4 u16 頭像號的起點（`FACE1`、`BUSTUP1` 是 4096），+6 u16 種類，+8 u32 張數。
  - +0x10 起是 256 bytes 的 LS11 字典。
- 0x110 起是每張 24 bytes 的索引：u32 寬、高、展開大小、壓縮大小、位置、0x32。
- 每張是 LS11 位元流（`ls11.get_codes`＋`ls11.recover`，用檔頭的字典）：
  - 最後一個碼的補位會多解出 1–3 bytes，要截到展開大小。
  - 壓縮大小等於展開大小的項目沒有壓縮，原樣存放。
- 展開後依序是寬×高的色號，然後是 256 色 RGB555 色盤（512 bytes）。
- 頭像檔：
  - `FACE0.TG4`：677 張 56×56 小頭像（含底框），256 色全用。658 張共用一組色盤，19 張各有自己的色盤。
  - `FACE1.TG4`：62 張，頭像號 4096 起，第 0 張是 8×8 的空白。
  - `BUSTUP0`／`BUSTUP1.TG4`：同順序的 304×300 半身像，太大不收（比照太閤立志傳III）。
- `PLNAME.TG4` 是 312 張 132×26 的城名圖。

## 劇本：SNR/SNR1–3.TR_（`koei_games.taikoh4_win_scenario`）

先前以為這是安裝綁定的保護，其實只是 EXE 裡的代換表。讀檔在 `0x581650`，解密函式在物件 `0x655B60`：

- SZDD 展開後，前 16 bytes 是明文 `TR4SCENARIO0000n`。
- 接著 0x2A bytes 是兩把 21 bytes 的金鑰（`TAI4SNR00n`、`TAI4TAI4SCENARIOn`），每 byte 經 EXE 檔案 0x1F8920 的代換表反查（`0x5BB61C`）。
- 其餘每 byte 經另一張表反查（`0x5BBF7B`）。這張表是第一把金鑰各字元的和 mod 4，去 EXE 0x1F8F38 的 4 個指標裡挑。
  - 金鑰區之後的第一個 byte 也被跳過。
- 解出來是 `ILNK` 封裝：+4 u32 段數（13），+8 起是各段位置。
  - 第 0 段是劇本說明（Big5）。
  - 第 8 段是 650 筆 48 bytes 的武將資料，第 9 段是 700 筆 48 bytes。
  - 第 10 段是人名：32 bytes 一筆，+6 姓（9 bytes）、+15 名，Big5。外字 F9DA 是「恒」。
  - 名字後面不一定清成 0，劇本 2、3 常留著 D8 D8 之類的雜值。

## 人物與頭像

- 三個劇本的人名都是同一份 725 筆，從人物 2 開始。劇本 2、3 有改名，例如松平元康到劇本 3 叫德川家康，匯出取劇本 3。
- 人物 0 是主角（木下藤吉郎，列伝是秀吉）。人物 1 沒有名字，列伝寫的是長宗我部元親的近侍。
- EXE 0x5581E0 初始化人物時，從檔案 0x1F4DE8 的表取每人的頭像：727 筆 (u16 頭像, s16 換裝起點或 −1)。
  - 人物 0–599 的頭像就是人物號，列伝（`MSG/TR4MSG17–20`）也是同樣的編號。599 是新武將。
  - 600–649 是「其他００–４５」「劇本０–３」，沒有臉。
  - 650–683 是文化人與女性（頭像 600–633）。
  - 684–699 的阿絹、志乃、小彩、8 位上忍、土御門蛇琉等人借用一般人物的臉。
  - 700–726 是一般人物（城守衛、米店老闆…，頭像 650–676）。
- 換裝起點每人 3 張（FACE1），共 18 人，例如藤吉郎 4104–4106、伊達政宗 4107–4109。新武將從 4097 起 7 張。
- 沒有人用的頭像：
  - 1 號。
  - 634–649：三位女性、8 張上忍、僧侶、商人、3 張忍者。數量和順序對得上 684–699，可能原本是這些人的專用臉。
  - 675：戴頭巾的足輕大將。
  - 這些匯出時歸「其他頭像」。

## 匯出（`taikoh4-win`）

- 644 個角色、738 張頭像。
- 小頭像有底框、256 色全用，所以是 `"opaque": true`。每張帶自己的色盤（`portraitPalettes`，共 19 組）。
- 分組：
  - 角色：女性（寧寧等、阿絹、志乃、小彩）、名人（文化人、上忍、土御門蛇琉）。
  - 頭像：一般人物、新武將、其他頭像。
