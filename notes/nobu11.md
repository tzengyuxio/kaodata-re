# 信長の野望・天下創世 with パワーアップキット（NOBU11PK, Windows 日文版）頭像相關格式

`dekoei.py export nobu11pk-win` 用到的格式。來源是 Steam 版（appid 628140，見 `notes/steam.md`），匯出用到的 `grp/KAO_M.N11` 與 `scenario/DBSCEDA10.N11` 複製到 `games/nobu11pk-win/`。

## 頭像：grp/KAO_S.N11、KAO_M.N11、KAO_L.N11

- 同一組臉有三種尺寸：S 56×70（1621 項）、M 96×120（1621 項）、L 240×240（1623 項）。依「不小於 64×80、最接近 64×80」的規則收 M。
- 封裝和革新相同（`F11N`，見 `notes/nobu12.md`），但每項 `T11N` 是 8 bit：22 bytes 檔頭（寬、高、貼圖寬、高，格式 byte 是 9）之後是 256 × B、G、R、X 的色盤，再接貼圖大小（128×128）的色號。只取左上的寬×高。
- 每張臉自帶色盤，所以用逐張色盤（`portraitPalettes`，相同的色盤只存一份）。有 405 張 256 色全用，色號 255 也是實際顏色，所以整個資料集是 `"opaque": true`，色號照原樣。
- 620–999 的 380 項是空白的臉，不收。

## 劇本：scenario/DBSCEDA??.N11

- 劇本有 01、02、03、04、08、09、10 七個。`SCEDA??.N11` 沒有人名，人名在同號的 `DBSCEDA??.N11`。
- 檔頭是 `NOBU11PKSCENARIOVERSI02`，726 起是一個 `LWC\x1a` 區塊（`ls11.lwc_decode`，同革新）。
- 解開後 0x1E884C 起是 1216 筆 123 bytes 的人物記錄：+0 姓（9）、+9 姓的讀音（17）、+26 名（9）、+35 名的讀音（17），Shift-JIS，讀音是平假名；+52 u16 頭像號（0xFFFF 沒有頭像），+54 起是生年、元服年、歿年；+119 u16 是連號（用來確認表的結尾）。
- 7 個劇本的人物與頭像都相同，只有名字隨年代改變。匯出用最後的劇本 10（1599 年）。

## 頭像的分配

- 槽 0–999 與 1112–1211 是武將，各用一張不同的臉：0–499、1000–1499、1501–1600。
- 槽 1112–1211 的 100 人（服部康成…）用 1501–1600，排在本體頭像區之後，和革新 PK 追加的是同一批人，判斷是 PK 追加，標 `pk`（放 `extra.bin`）。
- 槽 1000–1082 是公主：500–519 每張 4 人共用（不取名），565–567 是斎藤帰蝶、織田市、明智玉子專用，這 23 張分到 `姫`。
- 槽 1083–1111、1212–1215 是先代等，沒有頭像。
- 沒人用的 520–564、568–619、1500、1601–1620（一般武將、女性、くノ一、兵士等）分到 `其他頭像`，用途沒有追。
