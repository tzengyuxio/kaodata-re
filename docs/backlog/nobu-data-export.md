# 信長の野望歷代資料解析（給 koei-wiki）

## 結論

使用者要的是信長の野望歷代的人物、地理、事件、道具，以及各代的劇本選項。解析結果寫進 `notes/nobu<N>.md`，匯出交給 koei-wiki，格式由 koei-wiki 訂。

- 範圍（2026-11-06 使用者定）：先做 2–8 代。每代先做**人物與地理**，事件、道具、劇本選項留到下一輪。
- 初代、14–16 代不在這一輪：初代本地沒有遊戲檔，14 代沒買，15、16 代只有 Steam 版。
- 地點沿用 koei-places/1（koei-wiki `docs/places-format.mkdn`），`level` 填「國」「城」等遊戲裡的稱呼。人物的格式要和 koei-wiki 談：三國志第一次只交了主能力（`stats-export`），之後也要補交其他能力（使用者 2026-11-06），所以人物格式要三國志和信長共用，信長這次直接交全部欄位。

## 每代要解的

- **人物**：姓名、讀音、生年、壽命或歿年、一門／親族、身分、各劇本的所屬大名與居城、全部能力（含隱藏值）、技能與兵科適性、相性、義理。現況見 `notes/nobu-attributes.md`。
- **地理**：國或城的表、名稱、讀音、所屬地方、相鄰關係、大地圖位置，以及有沒有戰場圖。

## 主資料集

規則（使用者 2026-11-06 定，各系列共用，寫在 koei-wiki `docs/places-format.mkdn`）：資料取主資料集（PC-98 版或 Steam 版；Steam 有 PK 用 PK）。有中文版的代數，`name` 用中文版的人名地名，日文寫法放 `nameJa`（沒有 `nameZh` 欄位）。

格式：人物 koei-persons/1（koei-wiki `docs/persons-format.mkdn`，三國志與信長共用），地點 koei-places/1，列傳照三國志的 biography 格式。
